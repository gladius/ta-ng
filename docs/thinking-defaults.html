Why Opus 5 and 5.5 spend reasoning tokens when Opus 4.8 did not

Anthropic changed the default. Up to Opus 4.8, a request that says nothing about thinking runs without it. From Opus 5, the same request runs with thinking on, and on Opus 5.5 it cannot be switched off.

Checked against Anthropic's documentation on 13 November 2026. Reasoning tokens are billed as output tokens.

Opus 5.5 cannot switch thinking off: the references

Two separate pages of Anthropic's documentation say this, and both were read on 13 November 2026.

"Claude Fable 5.2, Claude Mythos 5.2, Claude Fable 5.1, Claude Mythos 5.1, Claude Fable 5, Claude Mythos 5, Claude Opus 5.5, and Claude Mythos Preview reject thinking: {type: "disabled"}. Thinking can't be turned off on these models."

Thinking, section "Turning thinking off"

The per-model table lists Claude Opus 5.5 as "Adaptive only", default "Always on", rejecting both "enabled" and "disabled" with a 400 error. Under the table: "Models marked Always on cannot turn thinking off."

Troubleshooting thinking, section "Thinking support, defaults, and rejected configurations by model"

A request that tries it on Opus 5.5 fails with this message:

"thinking.type.disabled" is not supported for this model. Use "thinking.type.adaptive" and "output_config.effort" to control thinking behavior.

The same page gives the reason: "thinking is always on for all of these models". Its advice is to leave the thinking setting out and control the amount with effort.

Opus 5 is different. It accepts "disabled" at effort "high" or below, and rejects it only at "xhigh" or "max".

What controls thinking on the newer models

Effort is the control. It has five levels: low, medium, high, xhigh and max. It steers how often the model thinks and how deeply.

  • Opus 5 defaults to high. Opus 5.5 defaults to medium.
  • On a model where thinking is on, the model still decides per request. A simple question may get no thinking at all.
  • Low effort means the least thinking the model will do. It is not a guarantee of zero.
  • On Opus 5, Anthropic advises lowering effort over turning thinking off. With thinking off, the model can write a tool call into its answer as plain text, so the call never runs.

How Token Auditor lets you test it

When starting a model audit, each model you try can carry its own thinking choice. It applies to every request in the audit, whether there are five or five hundred. The baseline is always re-run exactly as logged.

  • A setting the model refuses is left out, and the run is flagged on the audit page as not the request as logged.
  • Through the API, the same model can be tried several times in one audit, for example Opus 5.5 at low, medium and high effort side by side.
  • With the judge on, each row also shows whether the answers still hold, so you can find the cheapest setting that keeps quality.

Known gaps

  • The form has no "On" choice. Trying Opus 4.8 with thinking switched on needs the API today.
  • The form offers "Off" for every model, including the ones that refuse it.
  • The Opus rows in the table above come from Anthropic's documentation. We have not yet run them ourselves.
